# How we test (and why the list stays this short)

Most AI directories are built on the same three inputs: a submission form, a pricing page, and a description written by the vendor. That is why they read like press releases and why nothing in them is trustworthy.

This list uses a different bar. Below is exactly what a tool has to survive before it gets an entry — published so you can judge the list, and so submissions can be rejected on stated grounds rather than taste.

---

## Rule 01 — Every listing is visited

Before an entry exists, someone has:

1. Opened the site and reached the primary action
2. Run the main flow end to end at least twice
3. Read the actual pricing page — including the free-tier limits, not just the headline price
4. Found at least one thing the tool does badly

Step 4 is not decoration. **A review with no stated weakness is an advertisement**, and it does not get merged. If we cannot find a flaw, we have not used the tool enough.

---

## Rule 02 — No paid placement

Ordering is editorial. Two consequences that are worth stating explicitly:

- **If a tool is ours, the entry says so** — in the entry itself, not in a footer. A four-entry directory with no disclosure is just an ad with a table of contents.
- **Nothing is buried because a competitor asked.** Removal happens for exactly one reason: a better tool for the same job has taken the slot.

There are no affiliate links in this repo. If that changes, it changes at the top of the README first, in the same commit.

---

## Rule 03 — Short beats complete

There are thousands of AI tools. This catalogue stays small on purpose.

The operative test is not "is this good?" but **"is this the best thing for this specific job, and would I hand it to a friend?"** One strong entry per job beats fifty mediocre ones you have to sift. When a better tool shows up, the weaker one gets **removed**, not appended at the bottom.

A growing list is not a sign of health. It is usually a sign that nobody is deleting.

---

## What we record, and what we deliberately do not

**We record:**

| Field | Why |
|---|---|
| The specific job it does | "AI writing assistant" describes nothing |
| Free tier, in units you can plan around | 3 images/day beats "generous free plan" |
| Who it is for | A tool for teachers is not a tool for growth marketers |
| Where it falls short | The only field that makes the rest believable |
| Real alternatives, linked | A list whose only answer is "us" is worthless |

**We do not record:**

- Benchmark scores we did not run ourselves
- "Revolutionary", "game-changing", "seamless"
- Feature counts that grew by counting settings toggles
- Anything learned from a press release

---

## How entries get removed

A tool loses its slot when:

- A better tool for the same job is found and tested
- The free tier is removed or gutted without a pricing-page update
- The product changes job (it stops doing the thing it was listed for)
- It is abandoned — no update, no working signup, broken exports

Removal is not a judgment on the team. It is the mechanism that keeps the list worth reading.

---

## If you are submitting a tool

Open an issue and answer three things:

1. What one job does it do better than anything else?
2. What is the free tier, in units someone can plan around?
3. What is it bad at?

Issue number three is the one that decides whether the submission is taken seriously. See [CONTRIBUTING.md](../CONTRIBUTING.md).
