# Contributing

Thanks for wanting to improve the list. The bar is high on purpose — a short list is only useful if nothing mediocre gets in.

---

## Before you open an issue

Check that the tool is not already listed, and that it does one specific job. "An AI platform for everything" is not an entry; "0.3-second scores for resume ATS gaps" is.

---

## What a submission must contain

Open an issue with all three of these. **Missing any one of them means it will be closed**, not because the tool is bad, but because the entry cannot be written honestly without it:

1. **The job.** What single task does it do better than the current entry for that job?
2. **The free tier.** In units someone can plan around — "10 runs/day, no card", not "generous free plan".
3. **The weakness.** What is it bad at? Where does it break?

Number three is the load-bearing one. A review with no stated weakness is an advertisement.

Optional but appreciated: a screenshot of you actually using it, and the pricing page URL.

---

## What gets rejected

| Reason | Note |
|---|---|
| No stated weakness | Non-negotiable |
| Only a landing page, no hands-on run | This list only carries visited entries |
| Paid placement or affiliate arrangement | Against rule 02 |
| "Better than X" with no specifics | Say what it does differently |
| Duplicate of an existing job | The existing entry has to be beaten, not appended to |
| Pure marketing copy pasted from the vendor | Will be rewritten or closed |

---

## Editing an existing entry

Corrections are very welcome, especially:

- A free tier that changed
- A price that moved
- A feature that was removed
- A limitation we missed

Open a PR with the change and a link to where you verified it. "I used it and this did not work" is also valid — say what you did and what happened.

---

## Style

- **Sentence case** for headings
- **Specific numbers** over adjectives — "10 runs/day" not "ample free usage"
- **Link real alternatives** by name; do not link competitors' affiliate pages
- **Keep the disclosure line** in every tool entry
- English in `README.md` and `tools/*.md`; Chinese in `README.zh-CN.md` — keep both in sync when they change
